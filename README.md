SOCKETChat - A Learning Journey 📚
A real-time chat application I built to learn WebSocket communication with Socket.io. No frameworks, no database - just vanilla JavaScript and Node.js.

🌟 What I Built
SOCKETChat is a simple, real-time chat application where users can:

Choose a username and join the global chat

Browse and join different topic-based rooms

See who's online and typing in real-time

Send and receive messages instantly

🧠 What I Learned
Backend (Node.js + Express + Socket.io)
Setting up WebSocket connections with Socket.io

Managing real-time room-based communication

Handling user connections/disconnections

In-memory state management (no database)

Basic event-driven architecture

Frontend (Vanilla JavaScript)
Socket.io client implementation

Real-time UI updates without page refresh

Responsive design with mobile sidebar

Managing application state in memory

DOM manipulation for dynamic content

Key Concepts Applied
WebSockets: Real-time bidirectional communication

Event-driven programming: Listening and emitting events

Room-based architecture: Isolating chat spaces

State management: Tracking users, rooms, and messages

Responsive design: Mobile-first approach

🔧 Tech Stack
Frontend: HTML, CSS, Vanilla JavaScript

Backend: Node.js, Express.js

Real-time: Socket.io

Icons: Phosphor Icons

Deployment: Ready for Render/Vercel
